# HXH-C5 — Hunter × Hunter CTF Web Challenge

An anime-themed web exploitation CTF challenge from the Hunter × Hunter series.

## Quick Start

### Docker Compose
```bash
docker-compose up -d --build
```

Access the challenge at: http://localhost:30005

### Files
- docker-compose.yml - Port mapped to 30005:80
- src/ - Web application source
- mysql/ - Database initialization
- solve.py - Solution script
