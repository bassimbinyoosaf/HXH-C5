# HXH-C5 — Hunter × Hunter CTF Web Challenge

Anime-themed web exploitation CTF challenge.

## Quick Start

### Docker Compose
```bash
docker-compose up -d --build
```

Access: `http://localhost:30005`

## Files
- `docker-compose.yml` - Exposes port 30005:80
- `src/` - Web application source code
- `mysql/` - Database initialization scripts
- `solve.py` - Reference solution script
